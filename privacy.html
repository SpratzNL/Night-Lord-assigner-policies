Privacy Policy

The Night Lord Assigner Bot is used exclusively within a single Discord server and is not publicly distributed.

Data Collection

The bot only processes the minimum data required for verification:

  • Discord user ID and username
  • Messages submitted in the verification channel
  • Uploaded images used for verification

How Data Is Used

Data is used only to:

  • Verify MapleStory Night Lord character information
  • Assign Discord roles after successful verification
  • Diagnose verification errors when a user fails verification

Data Retention

Verification data is temporary.

  • If a user fails verification, relevant logs may be temporarily stored to identify the issue
  • Once the user successfully completes verification, all associated temporary data is deleted

Data Sharing

No data is sold, shared, or transferred to third parties.

Security

All stored data is limited to verification troubleshooting and is only accessible to the bot operator.
